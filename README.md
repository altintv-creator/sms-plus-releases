# SMS+ sürümleri

Bu depo yalnızca SMS+ kurulum dosyalarını ve uygulamaların okuduğu güncelleme bilgisini içerir. Kaynak kod burada değildir.

- **Windows:** [Releases](../../releases) sayfasında `SMSPlus-<sürüm>-setup.exe`
- **Android:** aynı sayfada `SMSPlus-<sürüm>.apk`

`desktop/latest.json` ve `mobile/latest.json` dosyaları, kurulu uygulamaların yeni sürümü bulması içindir.
